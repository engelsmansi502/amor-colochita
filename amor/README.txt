PROYECTO: Flores amarillas para Colochita 🌻

1. Abre una terminal dentro de esta carpeta.
2. Ejecuta:
   pip install -r requirements.txt
3. Ejecuta:
   python app.py
4. Abre:
   http://127.0.0.1:5000

La página incluye:
- Nombre/apodo personalizado: Colochita.
- Carta tierna y dulce.
- Flores amarillas animadas.
- Corazones flotantes.
- Melodía sencilla generada por el navegador.
- Enlace para buscar "Labios Rotos" de Zoé en YouTube.

Nota:
No se incluye la grabación de la canción. El botón abre una búsqueda de
la canción para que pueda reproducirse desde YouTube.
